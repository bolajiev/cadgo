# Demo and submission plan

## Demo object: cable clip

**Why:** small, flat, functional, fast to print, no supports, easy fit test, clear parametric edits.

- One known dimension / ruler in the photo.
- PLA, 0.2 mm layers, 2–3 walls, 15–20% infill.
- Print v1 immediately; print two final copies.
- Fit test: cable snap/fit and screw holes.
- Measure with calipers; show measured vs nominal.

## Story

“I have a photo of a part I need to replace. Cadgo asks what it is for, asks for my printer and bed, and turns the reference into editable CAD. I can correct the scale, change dimensions in plain language, validate printability, export parts, and print it.”

## Demo requirements

- Text-edit path must be visible (plain-language rule).
- Show sources/assumptions; do not fake certainty.
- Show one validator catch and fix.
- Show a physical print; a render alone is weak.
- Record a continuous unedited take of image → scale → edit → export.
- Keep a local build, pre-sliced file, spare print and backup video.

## Submission checklist

- [ ] Registration/eligibility confirmed.
- [ ] Licence/GPL position confirmed.
- [ ] Public repo, no secrets, credits complete.
- [ ] Hosted demo reachable logged out.
- [ ] Video under 3 minutes, public/unlisted, tested logged out.
- [ ] Write-up and category selected.
- [ ] Submit 9–10 Nov; save receipt.
- [ ] Freeze/tag submitted commit.

## Claims to use

- “Reference-to-parametric CAD for printable parts.”
- “Editable source, named dimensions, local compile.”
- “Printer-aware; scale confirmed; separate bodies; visible render check.”
- “A printable starting point, not a photogrammetry clone.”

## Claims to avoid

- First/only image-to-CAD.
- B-Rep, STEP-ready, feature tree.
- Watertight/print-ready guaranteed.
- Exact photo reconstruction or engineering accuracy.
- Any object/any photo.
- Fully local/private.
